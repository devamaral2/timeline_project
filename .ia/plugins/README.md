# Plugins

Manifestos de plugins registram finalidade, permissões mínimas, dependências e
como revogar a conexão. A autenticação ocorre fora do repositório.

O [`manifest.yaml`](./manifest.yaml) relaciona cada integração ao seu exemplo.
Os exemplos de Linear, Gmail, GitHub e ai-memory registram apenas finalidade e
permissões pretendidas. As conexões reais serão configuradas nas RAF-115 e
seguintes depois que os escopos de acesso forem confirmados.
