# Worktrees

Este diretório guarda convenções e wrappers para worktrees, nunca as worktrees
em si. Instâncias de execução ficam em `.ia/worktrees/instances/`, que é
ignorado pelo Git.

Os scripts atuais estão em `scripts/worktree/` e continuam sendo a interface
de operação até a RAF-114 avaliar o adaptador canônico.
