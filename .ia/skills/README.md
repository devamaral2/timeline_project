# Skills

Este diretório receberá somente skills próprias ou explicitamente aprovadas
para este repositório. Skills globais do agente não são copiadas
automaticamente; devem ser tratadas como dependências externas.

Uma skill deve conter seu `SKILL.md`, declarar escopo e evitar caminhos
absolutos, credenciais e estado de execução. A migração das skills existentes e
seus adaptadores fica na RAF-114.
