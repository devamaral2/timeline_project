# MCPs

Este diretório contém contratos e exemplos sanitizados de servidores MCP. Um
arquivo aqui não representa uma conexão ativa.

Regras:

- URLs, comandos e caminhos são placeholders configuráveis;
- tokens, headers, cookies e arquivos de credenciais nunca entram no Git;
- cada servidor documenta escopo mínimo, dependências e diagnóstico;
- configurações pessoais como Obsidian não entram no contrato por padrão.

O exemplo [`server.example.yaml`](./examples/server.example.yaml) mostra o
formato sem apontar para a máquina atual.
