# Plugins

Os manifestos registram finalidade, permissões mínimas, dependências e como
revogar cada conexão. A autenticação ocorre fora do repositório.

[`manifest.yaml`](./manifest.yaml) relaciona cada integração ao seu exemplo.
Linear, Gmail, GitHub e ai-memory só têm contratos sanitizados aqui; tokens,
cookies, perfis e configurações pessoais pertencem ao ambiente do agente.
